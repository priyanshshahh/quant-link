# QuantLink — Real-Time Financial Simulation Game

A multiplayer 3D quantitative-trading life-sim built on **SpacetimeDB**. Walk a
financial city, trade a **server-authoritative market driven by Geometric
Brownian Motion**, build a hedge fund (hire staff, buy property), purchase
vehicles, complete finance-education quests, and consult an **AI quant mentor**.
Every price move is computed on the server and streamed to all players at once.

> **Simulation, not real markets.** Prices are generated by a GBM process and
> the ambient "news" is a labeled simulator. Nothing here is financial advice or
> real market data.

## Stack / Architecture

| Layer | Tech | Responsibility |
|-------|------|----------------|
| Backend | **SpacetimeDB 2.x** module in **Rust → WASM** (`server/`) | All game state + logic: tables, scheduled GBM market ticks, atomic trades, firm cash-flow, quests, leaderboard. No external DB or message broker. |
| Frontend | **React 19 + React Three Fiber** (`client/`) | 3D world, trading terminal, HUD. Connects over WebSocket, subscribes to tables, calls reducers. |
| AI proxy | **Vercel serverless** (`api/`) → **Google Gemini** | Context-aware mentor + prompt-to-market "remix". The Gemini key lives only in the serverless env — never in the browser bundle. |

```
Browser (R3F client) ──ws──▶ SpacetimeDB module (Rust/WASM)  ← authoritative state
        │                         ▲  scheduled process_market_tick (GBM, every 2s)
        │                         └─ scheduled game_tick (firm cash-flow, leaderboard)
        └──POST /api/mentor,/api/remix──▶ Vercel function ──▶ Gemini (key server-side)
```

The quant core (GBM step, seeded replay RNG, firm accounting) lives in
`server/src/sim_math.rs`, a dependency-free module the reducers call into, so it
is unit-tested natively.

## Verified behavior

All claims below are from real runs on this codebase:

- **Rust tests**: `cargo test` → **13 passed, 0 failed** (GBM flatness at zero
  drift/vol, exact deterministic drift at `z=0`, Itô variance-drag, price
  positivity over 500k steps, log-returns matching `N((μ−σ²/2)dt, σ²dt)`; RNG
  determinism + `N(0,1)` moments; firm cash-flow invariants).
- **wasm32 build**: `cargo build --release --target wasm32-unknown-unknown`
  compiles clean (the module's real deploy target).
- **Client build**: `npm run build` succeeds; the built bundle contains **no
  Gemini key and no `googleapis` reference** — only the `/api/mentor` and
  `/api/remix` proxy paths (grep-verified).
- **AI mentor proxy**: a real mentor request returns **HTTP 200** with a
  complete, on-topic reply (diversification / beta / position sizing) in ~1.6s.
  With no key configured it returns 503 and the client falls back to offline
  heuristic advice.

## Quick start (3 steps)

Prereqs: [SpacetimeDB CLI](https://spacetimedb.com/install), Rust +
`wasm32-unknown-unknown`, Node 18+. Run `./setup.sh` once to install/verify
toolchain and generate client bindings.

```bash
# 1. Build + publish the module (starts a local server on :3001 first)
cd server && spacetime start --listen-addr 127.0.0.1:3001 &   # or a separate terminal
spacetime build && spacetime publish quant-link --server http://127.0.0.1:3001 --module-path . -c -y --anonymous

# 2. Generate bindings + run the client
cd ../client && npm install && npm run dev            # http://localhost:5173

# 3. (optional) AI mentor — set the key server-side, then run the /api proxy
cp ../.env.example ../.env    # add GEMINI_API_KEY (or GOOGLE_API_KEY); NOT a VITE_ var
vercel dev                    # serves /api/mentor and /api/remix locally
```

Without a Gemini key the game is fully playable; the mentor and remix features
fall back to offline/local logic.

## Gameplay

| Action | How |
|--------|-----|
| Move | WASD + mouse look (click to lock pointer) |
| Open trading terminal | Walk to the brokerage tower, press **T** |
| Talk to the AI mentor | Walk to the mentor building, press **E** |
| Buy/sell stocks | Market tab in the terminal |
| Hire staff / buy property | Firm tab (requires firm tier + cash) |
| Buy vehicles | Lifestyle tab |
| Upgrade knowledge | Portfolio tab |
| Remix the market | Type a prompt ("crash oil, moon AI stocks") |

## Configuration

- **Module name is `quant-link` everywhere.** Local host `127.0.0.1:3001`,
  production `maincloud.spacetimedb.com`.
- Client: `client/.env.example` → `VITE_SPACETIME_HOST`, `VITE_SPACETIME_DB`.
- Proxy: `.env.example` → `GEMINI_API_KEY` (or `GOOGLE_API_KEY`), optional
  `GEMINI_MODEL`.

## Deployment

Target is **SpacetimeDB Maincloud** (module) + **Vercel** (client + `/api`
proxy). One-time owner logins (`spacetime login`, `vercel login`) are required,
so the public deployment is **pending** — see `docs/PROJECT-NOTES.md` for the
exact deploy plan and commands.

```bash
# Module → Maincloud
scripts/publish-maincloud.sh          # spacetime login + publish quant-link

# Client + proxy → Vercel (set VITE_SPACETIME_HOST/DB and GEMINI_API_KEY in the
# Vercel project env first)
vercel --prod
```
